# Read the metadata of a pdf file

Pdfinfo displays various metadata related to a PDF file, such as title, subject, author, creator, and creation date.
### Useful commands:

To install pdfinfo :

```bash
sudo apt install poppler-utils
```

To Extract metadata:

```bash
pdfinfo file
```
